# ⚡ Electric Fan Animation

## 📌 About the Project
Electric Fan Animation is a simple animation project that visually represents the working of an electric fan. It demonstrates the rotation and movement of fan blades, creating a realistic visual effect of a running electric fan.

This project is created to demonstrate basic animation concepts and improve understanding of visual motion.

## ✨ Features
- Animated electric fan representation.
- Rotating fan blades.
- Simple and easy-to-understand animation.
- Visual demonstration of an everyday electrical appliance.

## 🎯 Project Objective
The main objective of this project is to demonstrate how animation can be used to represent the movement and working of an electric fan in a visual and interactive way.
